Craftlife

Craftlife is a crafting adventure simulation game with an isometric cartoon art style, offering both online and offline gameplay on iOS. Players collect and manage resources like wood, stone, cotton, and metal ore to build and upgrade production structures that convert raw materials into items such as Tumblers and T-Shirts. The game features drag-and-drop product delivery, experience-based progression up to level 100, and intricate quest systems.

I served as the lead frontend engineer responsible for implementing and integrating key features including the entire UI/UX system, resource management loop, crafting logic, and analytics tracking. Multiplayer systems included chat, friends, and Crafting Circles. Technical implementations covered PlayFab SDK, Google Sign-In, WebSocket and HTTP APIs, and platform-specific in-app purchase flows. I also handled release setup for both console and App Store deployments using Unreal Engine.

Warehouse Simulator

This simulator tool was developed in Unreal Engine for runtime scanning and transformation of in-game actors, with support for different NPC placed in the world. It features integration with the ZXing third-party library for barcode scanning on Windows and Linux. Core functionalities include dynamic actor manipulation, runtime transform editing, NPC spawning, and interactive element placement using QR and barcode recognition.

VR Shooter Game

An immersive VR game where players use snack guns to shoot and capture Snack Monsters. Each monster reacts uniquely based on the snack type. I implemented multiplayer functionality including player and AI UI replication and synchronization.

VR Training Simulator

A VR-based evaluation platform for ramp service employees, simulating real-world tasks and testing user decision-making. My role focused on player setup, Chaos vehicle integration, UI implementation, and task flow systems.
